1. 시나리오 제목

대학생 투자 수익 관리 시스템

2. 시나리오 (5~10줄)

최근 주식과 ETF 투자에 대한 관심이 높아지면서 자신의 투자 현황을 체계적으로 관리할 필요성을 느끼게 되었다.

본 프로그램은 사용자가 투자 이름, 투자 금액, 수익률 등의 정보를 입력하면 예상 수익을 계산하고 관리할 수 있는 투자 관리 시스템이다.

초기 버전에서는 단일 투자 정보를 입력하여 예상 수익을 계산하는 기능만 제공하지만, 이후 버전에서는 여러 투자 항목을 리스트로 관리하고 투자 통계를 제공하도록 확장된다.

최종 버전에서는 투자 정보를 추가·수정·삭제할 수 있으며 파일 저장 기능을 통해 데이터를 영구적으로 관리할 수 있다.

✨ 1차 과제 내용

파이썬 입문 수준에서 구현 가능한 투자 수익 계산 프로그램을 기획하였다.

사용자가 투자 이름, 투자 금액, 예상 수익률을 입력하면 예상 수익을 계산하고 출력하는 가장 기본적인 형태의 프로그램을 설계하였다.

향후 여러 투자 정보를 관리할 수 있도록 확장 방향도 함께 계획하였다.

🟩 [2차 과제: V2.0] 리스트 기반 투자 관리 시스템
✨ 2차 과제 업데이트 내용

기존 단일 투자 계산 기능을 확장하여 여러 투자 정보를 저장할 수 있도록 개선하였다.

사용자로부터 투자 이름, 투자 금액, 수익률을 반복 입력받아 리스트에 저장하였다.

리스트와 조건문을 활용하여 투자별 예상 수익을 계산하고 전체 투자 통계를 출력할 수 있도록 구현하였다.

또한 max(), len(), append() 등을 활용하여 가장 높은 수익을 기록한 투자도 확인할 수 있도록 설계하였다.

🛠️ Troubleshooting & 기술 회고
문제 1 : ValueError 발생

원인 :

숫자를 입력받아야 하는 곳에 문자를 입력하여 형변환 오류 발생

해결 :

int()와 float() 사용 위치를 재점검하고 올바른 입력 형식을 안내하도록 수정하였다.

문제 2 : 리스트 인덱스 불일치

원인 :

하나의 리스트만 값이 추가되면서 데이터 개수가 달라짐

해결 :

append()를 모든 리스트에 동일하게 수행하도록 수정하여 데이터 일관성을 유지하였다.

🛠️ Troubleshooting & 기술 회고
문제 1 : FileNotFoundError

원인 :

저장 파일이 존재하지 않는 상태에서 읽기를 시도함

해결 :

try-except를 활용하여 파일이 없으면 새로 생성하도록 처리하였다.

문제 2 : CSV 저장 형식 오류

원인 :

줄바꿈 문자를 추가하지 않아 데이터가 한 줄에 저장됨

해결 :

각 데이터 끝에 "\n"을 추가하여 엑셀에서 정상적으로 읽을 수 있도록 수정하였다.
