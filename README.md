# 📖 프로젝트 소개

최근 주식 투자와 재테크에 관심이 많아지면서  
투자 정보를 직접 입력하고 예상 수익을 관리할 수 있는 프로그램을 만들고자 하였다.

기존 2차 과제에서는 단순히 투자금과 수익률을 입력하여 수익을 계산하는 기능만 구현하였다.  
이번 3차 과제에서는 기존 프로그램을 확장하여 메뉴 기반 시스템으로 개선하고,  
함수(Function)를 활용하여 프로그램 구조를 체계적으로 설계하였다.

또한 투자 조회 기능과 전체 수익 분석 기능을 추가하여  
사용자가 자신의 투자 현황을 쉽게 확인할 수 있도록 제작하였다.

---

# 🛠 주요 기능

## 1. 투자 추가 기능
- 투자 이름 입력
- 투자 금액 입력
- 수익률 입력
- 예상 수익 자동 계산

## 2. 투자 조회 기능
- 저장된 투자 목록 출력
- 투자금 및 수익률 확인 가능

## 3. 투자 분석 기능
- 전체 예상 수익 계산
- 최고 수익 투자 항목 출력

## 4. 프로그램 종료 기능
- 사용자가 종료 메뉴 선택 시 프로그램 종료

# 🔧 Troubleshooting (문제 해결 과정)

## 문제 1
함수 내부에서 total_profit 값을 수정할 때 오류가 발생하였다.

### 해결 방법
global 키워드를 사용하여 전역변수에 접근하도록 수정하였다.

---

## 문제 2
투자 데이터가 없는 상태에서 분석 기능 실행 시 오류가 발생하였다.

### 해결 방법
리스트 길이를 먼저 확인한 뒤 분석하도록 조건문을 추가하였다.

---

## 문제 3
코드가 길어져 가독성이 떨어지는 문제가 발생하였다.

### 해결 방법
입력, 조회, 분석 기능을 각각 함수로 분리하여 코드 구조를 개선하였다.
